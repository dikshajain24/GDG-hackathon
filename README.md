# 🎥 YouTube Auto Replier using Streamlit & Google API

This Streamlit web app allows you to **automatically reply to comments** on an existing YouTube video using the **YouTube Data API v3**. It provides an easy-to-use interface for creators to engage with their audience in bulk.

## 🔧 Features

- Authenticate with your YouTube account using OAuth 2.0
- Fetch top-level comments from a specified YouTube video
- Automatically post a custom reply to each comment
- Simple and intuitive Streamlit UI
